# Stupid-inc-unreal-project

**Stupid-inc-unreal-project** is a school project using **Unreal engine 5.6.1**.

## 📦 Current Status: Archived with Playable Demo

This project is in the **Archived stage**, meaning it's not being worked on and not expected to continue, but has **Playable Demo on Releases**.

## 🛠️ Tech Stack

- **Unreal engine 5.6.1**
- **Unreal engine 5.6.1 Blueprints**
- **Blender 5.0.1**

## 🚀 How to Run

1. Get latest releases on https://github.com/Jupresson/Stupid-inc-unreal-project/releases/tag/PlayableDemo
2. Extract the build.zip file
3. Run project.exe on Windous pc
